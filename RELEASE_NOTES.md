Initial release of Ecowitt Atomic, an opinionated Home Assistant integration using Ecowitt's
local HTTP API.

- Supports multiple gateways, weather and soil readings, and Ecowitt sensor diagnostics.
- Tested with GW2000A and GW3000A gateways.
- Requires Home Assistant 2026.10.2 or newer.

Extract `ecowitt_atomic.zip` into `custom_components/ecowitt_atomic` in your
Home Assistant configuration directory, restart, then add **Ecowitt Atomic**
under **Settings → Devices & services**.
